
# Mi primera página web

## Descripción
Este proyecto consiste en una página web sencilla desarrollada utilizando HTML5. 
Su objetivo es practicar la estructura semántica de HTML.

## Tecnologías utilizadas
- HTML5: Para crear la estructura y el contenido de la página.


## Instrucciones para abrir el proyecto

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Localizar el archivo `index.html`.
4. Hacer clic derecho sobre el archivo y seleccionar **Open with Live Server**.

   También puedes abrir directamente el archivo `index.html` en tu navegador web.
